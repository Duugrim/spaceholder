# Быстрый старт: Сферы влияния

## Что это?

Объекты со сферами влияния (как территории в Stellaris): объекты одной стороны сливаются в общую территорию. Объекты и кнопка включения живут в модуле **Azimuth**, зоны рисует менеджер системы (`docs/code/reference/influence-zones.md`).

## Как использовать?

### 1. Создайте объект

- Включите модуль Azimuth. В Actors Directory создайте актёра типа **Объект Azimuth**
- Настройте блок «Влияние (SpaceHolder)»:
  - **Радиус** — в клетках
  - **Сила**
  - **Фракция** — перетащите системную «Фракцию»

### 2. Разместите на карте

- Перетащите объект на сцену
- Объекты с одной фракцией одного цвета и сливаются

### 3. Покажите зоны

В блоке фракции у хотбара нажмите «Переключить отображение влияния». Или в консоли (F12):

```js
game.spaceholder.influenceManager.enable()
game.spaceholder.influenceManager.disable()
```

## Цвета

- Цвет — `fColor` фракции, иначе детерминированный цвет по UUID

## Советы

- Радиус 5–10 клеток для нормального размера зоны
- Пересчёт автоматический, пока зоны показаны (создание и движение токенов, правка параметров объекта)
