# Пробитие стен выстрелами

Стены Foundry — бесконечно тонкие линии. Чтобы выстрел мог их пробить, стене задаются **материал** и **толщина**, а пробитие считается теми же правилами v3, что и пробитие брони (`resolveDamagePackage`, энергия снаряда против `AR = hardness × t²`). Сами стены Foundry остаются как есть: зрение, движение и свет работают без изменений.

> Стена **без материала** (или с неизвестным материалом) ведёт себя по-старому: останавливает любой выстрел. Существующие сцены не меняются, пока стенам не назначат материал.

## Данные на стене

`flags.spaceholder.wall = { material, kind, thickness }`. Поля — в конфиге стены (вкладка «Пробитие выстрелами», `templates/wall-shot-config.hbs`, `helpers/walls/wall-config.mjs`).

| Поле | Значение |
|------|----------|
| `material` | slug предмета типа `material` (бетон, кирпич, дерево, гипсокартон, стекло, скала — категория `structure`, каталог `scripts/generate-sh-catalog.mjs`) |
| `kind` | `thin` (по умолчанию) — перегородка; `solid` — грань сплошной массы |
| `thickness` | **мм**, как у брони. `thin`: толщина стены. `solid`: глубина «на случай, если дальней грани нет» (0 — бесконечная, не пробивается) |

Дверь, открытая (`ds = OPEN`), выстрелы не останавливает; закрытая — стена как стена (`isShotBlockingWall`).

### `thin` и `solid`

- **`thin`** — тонкая перегородка. Пересечение луча даёт «плиту» толщиной `T / sinθ` вдоль луча (θ — угол луча к стене, не меньше `MIN_SIN_THETA = 0.2`, чтобы скользящий луч не получал бесконечный путь), центрированную на точке пересечения.
- **`solid`** — граница массы: толстая стена, нарисованная двумя линиями, пещера, контур здания. Используется штатное **«Направление»** стены Foundry: `dir` указывает **открытую** сторону (откуда в стену «бьёт» луч). Пересечение со стороны открытого пространства — вход в массу, с другой стороны — выход. Толщина — реальный путь между входом и выходом. Без направления (`dir = BOTH`) сплошная стена считается `thin`.

Побочный эффект: односторонняя стена для зрения/движения односторонняя — для пещер и толстых стен это естественно (внутри породы никто не стоит).

## Алгоритм (`helpers/walls/`)

1. `_isHitLine` собирает пересечения отрезка со стенами (как раньше) — уже отсортированные по расстоянию.
2. `wallCrossingFromCollision` (`wall-data.mjs`) превращает каждое в `crossing { t, a, b, dir, kind, material, thickness }`.
3. `planWallPasses` (`wall-penetration.mjs`):
   - стены без материала — «непрозрачные»: останавливают выстрел (старое поведение);
   - из остальных `buildWallSpans` (`wall-spans.mjs`) строит **спаны** материала вдоль луча и **склеивает перекрывающиеся**;
   - спаны проходятся по порядку: `passSpan` прогоняет каждый элемент `applications` через `resolveDamagePackage` с одним слоем (материал, толщина спана). Через стену дальше летит только сам снаряд (осколки **своего** типа урона без метки `transferred`): удар, переданный стеной (проводимость, самоиндукция), остаётся стене. Остаток урона и энергии (`energy`, `armorDamageReduction` — теперь есть в `bodyHits`) идёт в следующий спан и в токены за стеной;
   - **спад по дистанции** (`energyAt`): каждая стена встречает снаряд, ослабленный пролётом от дула, а `carryAt` даёт остаток уже со спадом до токена. Уровень спада переносится в следующий сегмент (`levelAt` → `shot.penetration.energyLevel`). Без `energyAt` — без спада;
   - первый спан, который снаряд не пробил, заканчивает выстрел у своей грани.
4. `walkProjectileCollisions(collisions, onHit, shot, wallPlan)` (`hit-luck.mjs`): пробитая стена пропускается, остановившая — кладётся в `reached` и обрывает ход. Токены за пробитыми стенами получают `details.carry` — снаряд, оставшийся после стен. Без `wallPlan` поведение прежнее.
5. Пуля, вышедшая из тела, идёт по хвосту луча дальше: стены за телом проходят через `planWallPasses` уже с **остатком после тела** (`ShotManager._planWallPasses(..., projectile)`), см. «Пуля, вышедшая из тела» в [[SHOOTING_SYSTEM]].
6. `AimingManager._resolveHitImpacts` для такого токена применяет `carry` вместо полного снаряда (скользящее попадание режет уже его энергию, спад в нём уже учтён); запись об атаке (`_wallDiagnosticLines`, раскрытая панель выстрелов) пишет по строке на стену; `DrawManager.drawWallPass` рисует кольца на гранях входа и выхода.

### Углы и «корнер-кейсы»

Склейка спанов заменяет «ловца углов» и не требует порога расстояния:

| Случай | Что происходит |
|--------|----------------|
| Луч задевает угол из двух тонких стен | плиты перекрываются → одна склеенная, толщина меньше суммы |
| Луч через общую вершину сегментов | пересечения на одном расстоянии → плиты совпадают → считаются один раз |
| Срезается угол сплошной массы | вход и выход — реальная хорда, она автоматически тоньше полной толщины |
| Толстая стена из двух `solid`-линий | один спан = расстояние между гранями |
| Луч стартует внутри массы | спан от начала луча до грани выхода |
| Нет дальней грани | глубина `thickness` входной стены, 0 — не пробивается |
| Разные материалы перекрываются | перекрытие остаётся за более «твёрдым» (`hardness`), второй обрезается |
| Толстая стена из двух `solid`-линий с **разными** материалами | весь путь между гранями считается материалом **входной** грани (первой, в которую попал луч); материал выходной грани не учитывается. С другой стороны тот же выстрел считается материалом другой грани. Луч, стартующий внутри массы, берёт материал выходной грани |

Толщина — реальный путь по лучу, закон `AR = hardness × t²` не меняется. Это отличается от токена, где косой удар не меняет броню, а режет энергию снаряда (`hit-quality.mjs`); см. «Калибровка».

## Ограничения раунда 1

Пробиваются только прямые сегменты `line` с `onHit` = `stop` / `next`. Без изменений (стена останавливает выстрел):

- `need` (ракеты, осколочные боеприпасы) — взрываются на первом касании;
- `complexLine` (рикошет), `circle` / `cone` (АоЕ — стены только укрытие, бинарное), `swing` (ближний бой);
- выстрел без урона (нет `applications`).

Стены не получают повреждений: пробитая стена остаётся целой (раунд 2).

## Настройки и калибровка

- Толщина везде в **миллиметрах** — и у брони, и у стен (в конфиге стены поле «Толщина, мм», в чате «N мм»).
- **Масштаб берётся из сцены**, отдельной настройки нет. Стена типа `solid` — это геометрия, нарисованная на карте: её длину в пикселях надо перевести в миллиметры. Клетка сцены — `grid.size` пикселей и `grid.distance` единиц (`grid.units`, раздел «Измерения» в настройках сцены), так что `px/мм = (grid.size / grid.distance) / мм в единице`. Единицу читает `millimetresPerSceneUnit` (`walls/wall-data.mjs`): `m`/`м`, `km`/`км`, `cm`/`см`, `mm`/`мм`, `ft`, `yd`, `mi`, `in` (английские и русские названия, ед. и мн. число). Пустая или незнакомая единица — метры. Сцена «100 px = 1 m» даёт 0.1 px/мм; сменили дистанцию на 2 m — 0.05 px/мм. Без сетки то же самое (Foundry меряет в пикселях).
- Материалы стен (категория `structure`) заданы под **миллиметры**: бывшие «сантиметровые» значения пересчитаны (`hardness / 100` — она умножается на t², `integrityPerThickness` и `weightPerThickness` / 10), поведение прежнее: «бетон 20 см» = «бетон 200 мм». Значения всё равно стартовые. Результат против текущих боеприпасов (остаток урона после стены, `stop` — не пробила):

| Стена | 9×19 | 5.56 | 7.62×54R | .338 | .50 BMG |
|-------|------|------|----------|------|---------|
| гипсокартон 15 мм | 95% | 99% | 100% | 100% | 100% |
| дерево 50 мм | stop | 77% | 90% | 95% | 98% |
| кирпич 120 мм | stop | stop | 36% | 65% | 85% |
| бетон 200 мм | stop | stop | stop | stop | 41% |
| бетон 300 мм | stop | stop | stop | stop | stop |

## План (раунд 2 и далее)

- **Разрушение.** Состояние стены (`integrity`, `breachLoss` — резолвер уже возвращает обновлённые слои); *ленивое дробление*: попадание в длинную стену режет её на ≤ 3 сегмента, повреждение получает только участок попадания, участок с `integrity ≤ 0` удаляется. Двери не дробятся; для `solid`-пар кратер на обеих гранях. Все записи — через GM-действие (`gm-actions`, игроки не могут менять `WallDocument`), пачкой на выстрел, идемпотентно.
- **Раунд 3.** `complexLine` (рикошет решается первым, общий энергобюджет), АоЕ-урон по стенам с корректным LoS, частичное укрытие, ближний бой по стенам.
- **Раунд 4.** Инструменты ГМа: оверлей материалов/сплошной стороны, массовое назначение, автоориентация, предпросмотр пробития при прицеливании.
