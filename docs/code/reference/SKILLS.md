# Навыки персонажа

Структура на листе (вкладка «Навыки»). **Не** входит в формулу попадания и aiming — туда навык ещё не подключён.

## Данные актёра

`system.skills` (только `character`, [template.json](../../../template.json)):

- `levels` — разреженный объект `{ [nodeId]: 1–10 }`. Нет ключа = 0.
- `extras` — свободные записи `{ id, parentId, category, name, level }`.
  - `parentId` задан: ребёнок любого узла (пресет или extra).
  - `parentId` пуст: свободный навык категории `physical` / `mixed` / `knowledge`.

Уровень **0–10**. Ребёнок не может быть выше родителя; снижение родителя зажимает потомков и extras в поддереве.

## Пресет

Дерево физических: [module/helpers/skills/physical-tree.mjs](../../../module/helpers/skills/physical-tree.mjs) (зеркало [data/skills/physical-tree.json](../../../data/skills/physical-tree.json)).

Два корня: **бой** (`combat` → ближний/дальний → тип → класс) и **физразвитие** (`physdev` → лёгкая/тяжёлая). Свободного ребёнка можно повесить на любой узел, не только на класс.

Смешанные и знания: пресета пока нет, только extras.

Веса по глубине (черновик): корень 1, ближний/дальний 1.5, тип 2.5, класс 4, конкретное 5.

## Эффект

`getSkillEffect(actor, nodeId)` — взвешенное среднее по цепочке **от корня до узла**, нули **не** выкидываются:

`sum(level_i * weight_i) / sum(weight_i)` → 0–10.

Для extra без родителя эффект = уровень (вес 1).

## API

```js
game.spaceholder.getSkillEffect(actor, nodeId)
game.spaceholder.getSkillLevel(actor, nodeId)
game.spaceholder.getSkillPath(nodeId) // только пресет-узлы
```

Код: [module/helpers/skills/](../../../module/helpers/skills/). Лист: вкладка `skills`, три колонки (физические / смешанные / знания). Заголовки колонок закреплены, скролл в теле колонки.

Дерево: без шевронов. ЛКМ по навыку с детьми — свернуть/развернуть (чёрточка под началом имени; в раскрытом виде в середине стрелка вниз, от неё ствол). Лист — входящая линия заканчивается вертикальной засечкой. ПКМ по навыку: изменить уровень / добавить ребёнка / удалить (только extra). ПКМ по заголовку колонки — свободный навык в корне колонки. Уровень меняется только диалогом, не live-полем.
