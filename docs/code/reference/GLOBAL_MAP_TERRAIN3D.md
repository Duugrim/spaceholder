# 3D-рельеф глобальной карты

Канон рельефа — не клеточная сетка `unifiedGrid`, а heightmap высокого разрешения + splat из до четырёх биомов на тексель. Клеточный JSON (`flags.spaceholder.globalMapGridPath`) остаётся источником **импорта**.

## Файлы

Код: `module/helpers/global-map/terrain3d/`.

Данные мира: `worlds/<worldId>/global-maps/<sceneId>-terrain/`

- `meta.json` — размеры, bounds сцены, `verticalScale`
- `heights.png` — высоты 0–100, 16 бит в каналах R/G (Foundry не принимает `.bin`)
- `splat.json` — base64 ids/weights на тексель (по 4 биома)

Флаг сцены: `flags.spaceholder.globalMapTerrainPath`.

## Вид

Клиентский setting `spaceholder.globalMapView3d`. Кнопка-гора в HUD включает Three.js-оверлей: перспективная камера сверху (~32°), CPU-смещённый меш, Phong-свет и запечённые тени. Изолинии (5 / 10) — отдельная векторная геометрия, построенная пересечением горизонтальных плоскостей с треугольниками рельефа; в цветовую текстуру они не запекаются. Кастомный GLSL не используется.

Панель кистей — слева снизу над хотбаром, **перетаскивается** за полоску сверху. Импорт и клеточная кисть — левое меню HUD; «Редактировать» при 3D сначала выключает 3D.

Импорт из `unifiedGrid` делает smoothstep + гауссово размытие высот и смесь биомов на границах клеток, чтобы не оставались «майнкрафтовые» ступени. Старые terrain-файлы v1 игнорируются (текущая версия — 2).

Токены: `TokenDocument.x/y` не меняются от высоты террейна. `TokenDocument.elevation` — **относительная** высота над/под поверхностью (единицы дистанции сетки Foundry). 3D-билборды рисуются интерфейсным слоем поверх террейна; выбор, targeting, двойной/правый клик используют обычные Token API Foundry. Actor можно бросить из сайдбара прямо на 3D-рельеф. При переносе токена показывается путь, а позиция сохраняется только при отпускании указателя.

Регионы: те же `flags.spaceholder.globalMapRegions`; в 3D — заливка по рельефу и полупрозрачные стены по контуру. Реки в 3D не переносятся.

2D (когда 3D выключен) снова рисует клеточную карту — так работают импорт и «Редактировать». Тестовая сетка специально кладёт **крупные прямоугольники биомов** (не 32px-ячейки высот).

Осмотр из точки: `game.spaceholder.openLookFromPoint({ x, y })` или `{ token }` — отдельное Application V2, не вращение основной карты.

## Редактор (GM)

Кисти: raise / lower / smooth / flatten / noise / paint biome. Гауссово ядро по сэмплам heightmap, не по клеткам Foundry. Undo на штрих. Save пишет PNG + `meta.json`.
