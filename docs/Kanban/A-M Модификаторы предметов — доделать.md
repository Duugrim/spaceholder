# Модификаторы предметов — доделать

Вкладка «Модификаторы» листа одежды/снаряжения (`templates/item/item-wearable-sheet.hbs`) показывает только уже существующие строки — добавить новую нельзя.

- Кнопки «+» (добавить строку) и «×» (удалить строку) для блоков: характеристики, производные, параметры (`system.params`: гравитация, внимательность, воля, стартов хода).
- Блок «Параметры» в шаблоне отсутствует (данные `system.modifiers.params` и цели `characterModifierTargets.params` есть).
- Проверить: у выпадающего списка цели условие выбранного пункта `(eq ../../mod.targetId t.id)` не видит `mod` — сохранённая цель может не показываться в списке.
- После доделки добавить в конец карточки проверку «Модификаторы одежды» (на листе одежды нет кнопки «+»).
