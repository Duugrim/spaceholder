# Реальные навыки

Сейчас в пресете физических навыков и в «Смешанных» / «Знаниях» — заготовки. Нужен настоящий список: что именно умеет персонаж в игре (оружие, атлетика, ремёсла, науки…) с уровнями 0–10 и связкой с боем (`getSkillEffect` пока не в формуле попадания).

Структура и правила дерева — в [[NR Навыки — структура]]; представление — [[C-M Переработка UI навыков в древо]].

Бюджет навыков (`skillBudget` из [[Характеристики актёра]]) пока только показывается на листе: дерево он не ограничивает — подключить, когда будет настоящий список.
