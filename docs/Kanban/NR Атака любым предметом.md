# Атака любым предметом

Атака — возможность предмета: `item.canAttack` / `item.attack({ token })` (`module/helpers/weapon/attack-chain.mjs`, `canAttackWithItem` / `attackWithItem`). Сейчас `canAttack` = оружие v3 с линиями.

Цель: любой предмет без функционала оружия можно использовать для удара тупым предметом.

- Расширить `canAttackWithItem` / `attackWithItem` веткой «импровизированная атака» (не плодить отдельный путь).
- Параметры удара от массы/материала предмета — продумать.
- HUD и лист подхватят автоматически (кнопка «Атаковать», ⌖ на карточке).
