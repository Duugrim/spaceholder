# Инструменты редактирования стен

Стены редактируются по одной в конфиге стены. На сцене с десятками стен это неудобно.

## Сделать

- Массовое редактирование: выбрать несколько стен → задать материал, толщину, тип, направление сразу. Либо макросы для этого.
- Материал в конфиге — не выпадающий список (материалов уже много, станет больше), а **слот, в который перетягивают материал**. Хранить ссылку (UUID, как у фракции глобального объекта), чтобы правка статов материала сразу действовала на стены; запасной вариант — копия статов на момент перетаскивания (хуже).
- Подсветка/оверлей материалов и сплошной стороны на сцене, автоориентация, предпросмотр пробития при прицеливании (раунд 4 из [[NR Пробитие стен]]).

Толщина стен теперь везде в миллиметрах (как у брони).
