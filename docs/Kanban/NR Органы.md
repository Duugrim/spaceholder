Делается вместе с [[NR Анатомия — группы]] (`inners` на части). Не отдельные цели выстрела.

## Модель

- Клетки на сетке нет. Живут внутри части.
- Отдельного HP нет. Статусы: норма / повреждён / уничтожен.
- Доля части (`%`). Сумма органов в части ≤ 100.
- После урона в часть: один ролл по суммарному % — зацепили ли орган и какой.
- Пример: голова — глаза и уши (без левый/правый).
- Не путать со **сторонами** (`faces`): сторона — слот брони, орган — ролл после урона.

Тип попадания / несколько роллов на оружие — не плодить сразу.

## Проверить руками

1. Редактор части: вкладка Органы, сумма % ≤ 100, нет клетки на сетке.
2. Голова humanoid: глаза / уши / мозг как inners.
