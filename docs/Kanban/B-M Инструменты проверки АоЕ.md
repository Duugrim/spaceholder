# Инструменты проверки АоЕ

Часть опций payload'ов нечем быстро проверить руками: править JSON и перезагружать страницу ради каждой опции слишком долго. Из-за этого проверены только по доверию `excludeDirectHit`, `ignoreDirectHitCover`, `lineOfSight: false`, ширина «тени» за целью.

## Сделать

- Диалог GM-прицеливания (`showAimingDialog`) получает поля опций АоЕ (`coverageMode`, `lineOfSight`, `excludeDirectHit`, `ignoreDirectHitCover`, `coverageForFullEffect`, радиус) и правит копию payload без перезагрузки.
- Либо набор тестовых предметов/payload'ов по одному на опцию («бахни этим — должно сработать так-то»), когда предметов станет достаточно.
- Тестовое оружие с несколькими линиями и режимами (3 режима, 2+ линии) — для вкладок линий и режимов в быстром HUD. Проверка, которая на него ждёт (перенесена из [[Быстрый HUD выбранного токена]]): 2+ линии — вкладки линий (подсказка с ценой ОД) и режимы активной линии; смена линии применяет первый режим; платная смена списывается сразу, без окна.
