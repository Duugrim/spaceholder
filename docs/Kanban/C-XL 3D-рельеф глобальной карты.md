# 3D-рельеф глобальной карты

Реализовано (`helpers/global-map/terrain3d/*`). Технически работает, но нужно много доработок; проверяется отдельно.

## Проверить руками

Сцена с `isGlobalMap`, жёсткое обновление (F5).

- [ ] Кнопка-гора сразу показывает 3D-карту (не серый экран). Панель кистей слева снизу над хотбаром, перетаскивается за верхнюю полоску.
- [ ] Импортированная карта: склоны сглажены, без квадратных «ступеней»; биомы могут чуть смешиваться.
- [ ] Raise/Lower работают по видимой 3D-карте без «Сохранить карту».
- [ ] Выключить 3D → клеточный импорт/редактор. «Редактировать» само выключает 3D.
- [ ] «Глаз» открывает окно осмотра.
