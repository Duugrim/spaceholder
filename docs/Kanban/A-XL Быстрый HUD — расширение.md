# Быстрый HUD — расширение

Цель: лист персонажа открывается для тонкой настройки, а почти всё обычное делается из быстрого HUD (принцип записан в `docs/code/guides/UI_DESIGN_GUIDE.md`, 1.7). Продолжение [[Быстрый HUD выбранного токена]].

## Раскладка

- Шире: **блок с портретом, именем, состояниями и кнопками уходит влево**; его можно свернуть до иконки и имени. Слева же — развёрнутая информация и доп. кнопки (или сразу видно — менее принципиально).
- **Справа разворачивается быстрый инвентарь**: короткий, низкие строки, мелкие иконки, фильтр по типам — чтобы найти простое, не открывая лист.
- Почти весь нижний центральный блок — под **действия**. Сейчас там половина блока: входят три-четыре действия, даже если развернуть; необычным действиям должно быть просторно.

## Действия

- Общий список — только особые действия с предметами. Простые (снять, убрать, выбросить, показать) и «Взаимодействовать» не показываются, пока не в избранном (сделано; добавляются из превью инвентаря).
- Добавление в быстрый доступ — удобной кнопкой в интерфейсе, а не через ПКМ; по аналогии со звёздочкой избранного у действия, возможно заменяет иконку.

## Инвентарь листа

- Фильтры по типам (и общая фильтрация), настраиваемая высота строк: средние иконки не нужны, большую покажет превью.
- Иконки конкретных предметов заменить собираемыми иконками типов предметов и их функций.

## Прочее

- Эффекты (статусы) пока только у рамки токена, как в ваниле; в HUD и на листе их нет — после того как в системе появятся собственные эффекты.
- Тестового оружия с несколькими линиями и режимами нет — нужно, чтобы проверять вкладки линий (см. [[B-M Инструменты проверки АоЕ]]).
