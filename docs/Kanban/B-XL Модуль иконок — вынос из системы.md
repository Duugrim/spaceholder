Редактор SVG-иконок (`icon-library/*`, `icon-picker/*`) выделен в отдельный модуль **Iconic** (`E:\FoundryVTT\Data\modules\iconic`, свой git-репозиторий, коммитов пока нет). Форма фона и щиты: [[B-M Фон иконок — шестиугольник и щиты]].

## Решения владельца (2026-10-25)

- Название — Iconic (id `iconic`; в реестре Foundry пакета с таким id не нашлось).
- Библиотека game-icons поставляется целиком, плюс «подбросить свои». Группировка по типу, не по автору; автора видно в окне и в `CREDITS.md`.
- Пресеты стилей не нужны: «взять прежнюю из `generated` и изменить» (уже работает, см. ниже).
- Делаем: деление поля щита, смещение/поворот/отражение иконки, предупреждение о низком контрасте и цветовые подсказки, двойной контур.
- Из «Потом» больше ничего (растр, автоориентация гекса, градиент/тень, свой контур, угловой значок — не нужны).
- «Вернуть прежнее» и очистка `generated`: только если недорого (см. ниже, рекомендация — очистку не делать).
- Свой браузер иконок — да, но без лагов (раньше были сильные).

## Точки входа (подтверждено в Foundry 14)

- **Клик по портрету не перехватываем** (решение владельца 2026-10-26): он остаётся штатным и за Tokenizer. В первой версии клик перехватывался (с Shift как обходом) — убрано: пути входа должны соседствовать со штатным выбором файла и Tokenizer, а не заменять их.
- Меню окна листа (три точки, Application V2): `getHeaderControlsApplicationV2` + `app.options.actions['iconic-edit']` (обработчик вызывается с `this` = окно).
- Кнопка в заголовке листа на Application V1 (PF2e и др.): хуки `getActorSheetHeaderButtons`, `getItemSheetHeaderButtons` (как у Tokenizer), `buttons.unshift({ label, icon, class, onclick })`.
- Контекстное меню каталогов (ПКМ): `getActorContextOptions`, `getItemContextOptions`.
- API: `game.modules.get('iconic').api` = `edit({ document, field?, tokenDocument?, factionColor?, startDir? })`, `pick({...})`, `canEdit(document)`.

## Хранение

- Результат (`generated`) — в папке мира `worlds/<мир>/iconic/generated` (настройка): остаётся с миром, если модуль удалить. В `modules/<id>/storage` писать нельзя: при удалении модуля пропадут портреты.
- Встроенная библиотека — `modules/iconic/library/` (поставляется). Свои иконки — `modules/iconic/storage/custom` (флаг `persistentStorage`: переживает обновление, общая для миров; `FilePicker.upload` разрешён только в `storage`).
- Запечённый SVG хранит исходник и стиль в комментарии `iconic-bake`; старая метка `spaceholder-bake` читается.

## Библиотека и браузер (дизайн)

- Источники: репозиторий `github.com/game-icons/icons` (36 папок авторов + badges, 4,3 МБ по данным GitHub API) даёт SVG и автора; теги — страницы сайта `game-icons.net/tags/*.html` (134 тега в два уровня; из них наши 45 папок в `assets/icons`). В нашей копии 3885 файлов, 2854 уникальных имени (иконка лежит в каждой своей тег-папке), автора в них нет — `license.txt` общий.
- Идентификатор иконки — `автор/имя` (у разных авторов бывают одинаковые имена).
- Тип: группа верхнего уровня дерева тегов по приоритету + все теги ищутся.
- Лаг: предположительно от десятков одновременных загрузок отдельных SVG. Схема без него: весь индекс (id, имя, теги, автор, номер миниатюры) одним JSON в память, поиск и фильтр по памяти; миниатюры — атласы-спрайты по категориям (одна картинка на категорию, покраска через CSS-маску под выбранный цвет); сетка виртуальная (в DOM только видимые ячейки); настоящий SVG грузится только для выбранной иконки. «Мои иконки» = `generated`, свежие сверху, ленивая подгрузка. До того, как строить поверх, замерить на 2854 локальных иконках.
- Для сборки нужны скачивания (с разрешения владельца): клон репозитория, 134 страницы тегов, растеризатор для атласов (`@resvg/resvg-js`). Выполнено 2026-10-26.

### Что получилось (этап 3)

- Состав: 4180 иконок, 36 авторов, 134 тега в 37 группах (+ «Прочее»: две иконки, которых нет на страницах тегов). 59 «значков» (`badges`, рамки 256×256) в набор не взяты. Неописанные на сайте иконки `tarot-11…21` получили теги соседей по первому слову имени.
- Данные: `library/index.json` (169 КБ, одним файлом в память), `library/icons/<автор>/<имя>.svg` (7 МБ, исходные файлы), `library/thumbs/sheet-NN.png` (17 листов 1024×1024, ячейка 64 px, всего 1,9 МБ), `CREDITS.md` (56 КБ, все авторы и все иконки), `library/license.txt` архива. Пересборка: `node tools/fetch-tags.mjs`, `node tools/build-library.mjs` (см. README модуля).
- Листы — не обычный PNG от resvg (6,2 МБ), а палитровый PNG на 16 уровней прозрачности (1,9 МБ): миниатюры используются как CSS-маска, цвет задаётся любым, один лист на сотни иконок.
- **Замеры** (headless Chrome, программная отрисовка, 1100×780): индекс грузится и собирается за ~20 мс; поиск — 0,7 мс на запрос; все 17 листов декодируются за ~90–180 мс; прокрутка всей библиотеки (4180 иконок) на скорости 9000 px/с — кадр в среднем 13,3 мс, максимум 13,5 мс, ни одного кадра длиннее 20 мс; в странице не больше ~255 ячеек. Вкладка «Созданные» (450 запечённых SVG, обычная прокрутка 1800 px/с, файлы ещё не в кэше): кадр в среднем 13,3 мс, максимум 18 мс; при резком пролистывании «свайпом» с холодным кэшем бывают кадры по 40 мс.
- «Созданные» упорядочены по недавности через клиентскую настройку `recentIcons` (у `FilePicker.browse` нет времени изменения), остальные файлы — по имени. «Свои SVG» — `modules/iconic/storage/custom` (подпапки = категории слева), кнопка открывает файловый браузер там же (загрузка).
- Перевод: названия 135 тегов на русский (`ICONIC.Library.Tags.<slug>`), поиск находит иконки и по русскому названию тега. Названия самих иконок остаются английскими (как просил владелец).
- Подпись автора: в запечённый SVG из библиотеки пишется комментарий `iconic-credit: Icon "…" made by … (CC BY 3.0), available on …`; у иконок из «Свои SVG» его нет.

## Лицензия

CC BY 3.0 (часть авторов CC0 — по `license.txt` архива). Сайт просит «Icons made by {автор}. Available on game-icons.net». Текст лицензии (§4): имя автора, название работы, URI; для адаптации — указание, что работа использована; «в любой разумной форме, соответствующей носителю». Список авторов в README и `CREDITS.md` — обычная практика (так делает существующий модуль `game-icons-net`), но юридической гарантии это не заменяет. Дополнительно: автор и ссылка в окне у каждой иконки, автор и лицензия в метаданных запечённого SVG (credit переезжает вместе с производной). Положить в модуль `license.txt` архива.

## Очистка и «вернуть прежнее»

- В Foundry 14 у клиента нет API удаления файлов (`FilePicker`: browse, createDirectory, upload) — очистка может только показать список неиспользуемых файлов, удалять придётся вручную.
- Проверка использования дешёвая (актёры, предметы, токены сцен в памяти — миллисекунды; паки — через `getIndex({fields})`), но запечённый файл весит ~2–3 КБ: тысяча файлов — несколько МБ. Рекомендация: очистку не делать, «вернуть прежнее» закрыть вкладкой «Мои иконки» и (если надо) флагом с прошлым путём на документе.

### Что получилось (этап 2)

- **Деление поля** (`scripts/lib/bg-division.mjs`): 12 вариантов (рассечённый, пересечённый, скошенный, скошенный слева, стропилом, андреевский крест, четверочастный, глава, гиронный, вертикальные и горизонтальные полосы, шахматная доска) на любой форме, не только на щитах. Второй цвет закрашивает часть поля, обрезается по фигуре; при включённой обводке линии деления рисуются её цветом. Прозрачность фона применяется ко всему полю разом (цвета не смешиваются).
- **Второй контур**: узкая полоса внутри края на одинаковом расстоянии у любой формы (толстая обводка формы, обрезанная по форме, минус тонкая в маске: «копия пути поменьше» дала бы неравные отступы у щитов). Зазор считается от внутренней кромки обводки (если она включена). Цвет, толщина и зазор настраиваются.
- **Иконка**: поворот (−180…180°), сдвиг по X и Y (−50…50 %), отражение по горизонтали и вертикали, кнопка сброса. Это свойство одной иконки: стиль (цвета, форма…) запоминается для следующей, а поворот, сдвиг и отражение — нет.
- **Контраст** (`scripts/lib/color.mjs`): формула WCAG; предупреждение ниже 3:1, подсказки стараются дать 4,5:1. Каждый цвет поля судится отдельно: на нём иконка читается своим цветом или обводкой (обводка считается, если она непрозрачнее 50 % и толще 0), решает самый слабый цвет. Белая иконка с чёрной обводкой на тёмно-красном поле с золотым делением — норма (на золотом читает обводка, на красном белая заливка). Предупреждения нет, если фона нет или он прозрачнее 50 %. Подсказки: цвета иконки (тот же оттенок с изменённой яркостью, белый, чёрный, цвет фракции из `factionColor`) и цвета фона; клик применяет цвет.
- **Цвет фракции находит сам Iconic** (`scripts/lib/color-hints.mjs`): цвет из `system.fColor` у самого актёра (фракция) и цвет фракции по UUID в `system.gFaction` (глобальные объекты Azimuth); работает и для токена (берётся его актёр). Причина бага: раньше цвет приходил только в аргументе `factionColor`, а его считал лист SpaceHolder, поэтому собственные пункты Iconic («⋮», ПКМ) цвета не знали. Явный `factionColor` по-прежнему главнее. Другие модули добавляют цвета хуком `iconic.colorHints` (`hints.push({ color, label })`), код Azimuth для этого не менялся.
- Без деления и второго контура SVG устроен как раньше (один `<path>` на фон); иначе появляются слои `clipPath`/`mask`.
- Код редактора: цвета, числа, флажки и пары «ползунок + число» теперь описаны таблицами, а не цепочкой `if`.
- **Окно редактора переделано после первой проверки в Foundry**: две колонки (слева предпросмотр, предупреждение о контрасте, «Применить к» с подписью над списком и кнопки; справа панели «Иконка» и «Фон»), у каждой строки название в отдельной колонке, группы элементов в одну линию, подписи короче («Толщина, %»). Высота окна `auto`, ширина 880 px: окно помещается целиком без прокрутки (проверено автоматически: нет переноса подписей, нет переполнения строк, русский и английский, с видимым предупреждением и делением поля). «Применить к» по умолчанию «Оба» (для актёра).
- **ПКМ в каталогах не появлялся из-за времени регистрации**: боковая панель рисуется в `initializeUI()` до `ready`, меню каталога собирается при её первом рендере и тогда же вызывает `getActorContextOptions` / `getItemContextOptions`; хуки, поставленные на `ready`, опаздывали. Теперь всё регистрируется на `init`. Пункт меню содержит ключи Foundry 14 (`label`, `visible`, `onClick`) и 13 (`name`, `condition`, `callback`).
- Копия `bg-shapes.mjs` в системе (для старого редактора) была заморожена и удалена на этапе 4: формы фона живут только в модуле.
- Тесты модуля: `npm test` (Node: деления, цвет и контраст, параметры; в headless Chrome/Edge — `tests/run-browser.mjs`: 13 проверок пикселей запечённого SVG).

### Что получилось (этап 4)

- Первая версия этапа оставляла связь: файл `module/helpers/iconic-link.mjs` и кнопку с иконками у портрета на всех листах (она звала Iconic, без модуля — предупреждение). Владелец решил, что связь не нужна: Iconic работает сам, а кнопка у глобального объекта лишняя. Связь и кнопки убраны целиком.
- Удалено: `module/helpers/icon-library/` (библиотека, запекание, миграции, `bg-shapes.mjs` с тестом), `module/helpers/icon-picker/` (окно, выбор, применение, мост), `templates/icon-picker/`, окно-SCSS `_icon-picker.scss`, кнопки `sh-portrait__pick` с шести шаблонов (персонаж, NPC, фракция, глобальный объект, лут, предмет) и их обработчики на листах актёра и предмета, запись в прелоаде шаблонов, всё про иконки в `game.spaceholder` (`pickIcon`, `applyIconPathToActorOrToken`, `getIconLibraryIndex` и другие), запуск миграции запечённых SVG при старте и регистрация настроек `iconLibrary.root` и двух флагов миграции (их значения в мирах остаются лежать без дела). Языковой блок `SPACEHOLDER.IconPicker` убран целиком (66 ключей в каждом из двух языков).
- **Что вернул после удаления SCSS:** вместе с окном пропали базовые стили `.sh-portrait` (размер 100×100 и `position: relative`), на которых держится портрет на листах фракции, глобального объекта и NPC. Они возвращены отдельным файлом `src/scss/components/_portrait.scss` (без кнопки).
- Выбор иконки маркера в редакторе событий таймлайна — обычный выбор файла Foundry (код без Iconic, 15 строк): таймлайн переезжает в Azimuth, у которого своя связь с Iconic.
- Цвет фракции находит Iconic по `system.fColor` и `system.gFaction`; лист актёра системы сам его больше не считает. Не предлагается только запасной цвет из хеша UUID, который лист подставлял фракции без цвета.
- **Цепочка Iconic → Azimuth → SpaceHolder проверена без Foundry** (одноразовый скрипт с настоящим классом `Color` из Foundry и именами полей из `template.json` системы и из моделей Azimuth; постоянные тесты `tests/faction.test.mjs` в модуле, 15 штук): глобальный объект Azimuth (`gFaction` = UUID) → фракция системы (`fColor` строкой) даёт её цвет; то же для фракции Azimuth (поле `ColorField`), для ссылки `@UUID[...]` и для токена объекта на сцене; битый цвет и пустая фракция ничего не предлагают. В живом Foundry цепочка не проверялась.
- Старые запечённые файлы из `worlds/<мир>/spaceholder/icon-library/generated` остаются картинками как есть; Iconic открывает их на правку (метка `spaceholder-bake` читается).
- Проверено без Foundry: 32 Node-теста системы проходят, все относительные импорты в `module/` разрешаются (кроме одного старого в `helpers/legacy/old-token-visibility.mjs`), SCSS собирается, весь `npm test` модуля проходит.
- Подключить Iconic зависимостью в `system.json` нельзя: модуль нигде не опубликован, а связи системы с ним больше нет.

- [x] **Повторное открытие.** Снова клик по портрету, сделанному выше: окно открыто на исходной иконке с теми же цветами, формой, скруглением и «Вписать иконку».
- [x] **Правка из generated.** В редакторе «Выбрать иконку» → вкладка «Созданные» → выбрать сделанную иконку: редактор переключается на исходник с его настройками, фон не накладывается второй раз.
- [x] **Цель.** «Токен»: меняется только прототип токена актёра; «Оба»: и портрет, и прототип токена. Для предмета выбора цели нет.
- [x] **Настройка.** «Добавить Iconic в меню листов» выключить: пункт из меню окна (и кнопка на листах Application V1) пропадает, ПКМ в каталогах остаётся.

### Браузер иконок (этап 3)

В редакторе кнопка «Выбрать иконку» открывает «Библиотеку иконок».

- [x] **Прокрутка.** Вкладка «Библиотека» → быстро прокрутить колесом и перетаскиванием ползунка от начала до конца: иконки появляются сразу, без подвисаний и пустых плиток. Окно можно растягивать: число колонок меняется, ничего не ломается.
- [x] **Категории.** Слева выбрать «Оружие»: над сеткой появляются кнопки подтегов («Клинки, мечи и ножи», «Топоры»…); выбрать подтег — список сужается, «Все» возвращает. В списке слева у каждой категории число иконок.
- [x] **Поиск.** Ввести «sword» — список сужается сразу; «sword lorc» — только мечи автора Lorc; при русском интерфейсе «череп» находит иконки с тегом «Черепа». Счётчик справа от вкладок показывает «N из 4180».
- [x] **Сведения.** Клик по иконке: справа крупный предпросмотр, название, автор (ссылка), лицензия, теги. Клик по тегу справа переключает фильтр на этот тег. «Открыть на game-icons.net» открывает страницу иконки.
- [x] **Выбор.** Двойной клик по иконке (или Enter, или «Выбрать»): браузер закрывается, иконка в редакторе, превью в выбранном цвете. Крестик или «Отмена» закрывают браузер, редактор остаётся как был.
- [x] **Клавиатура.** Клик по плитке, затем стрелки, PageUp/PageDown, Home/End двигают выделение и прокручивают сетку.
- [x] **«Созданные».** Сделать 3–4 иконки и открыть браузер снова: вкладка «Созданные» — новые первыми; иконки видны в своих цветах и формах.
- [x] **«Свои SVG».** Пока пусто: подсказка с путём `modules/iconic/storage/custom`. «Добавить свои SVG…» открывает файловый браузер Foundry в этой папке: загрузить 2 SVG, одну в подпапку, закрыть — список обновился, подпапка стала категорией слева, чёрные иконки видны на сером фоне. Выбрать одну: попала в редактор.
- [x] **«Выбрать файл…»** в браузере открывает обычный выбор файла Foundry; выбранный файл попадает в редактор.
- [x] **Подпись автора.** Сделать иконку из библиотеки, открыть её файл из `worlds/<мир>/iconic/generated` текстовым редактором: вверху комментарий `iconic-credit: Icon "…" made by … (CC BY 3.0)…`. У иконки из «Свои SVG» такого комментария нет.

### Редактор (этап 2)

В окне Iconic включить «Фон» и выбрать форму щита (например «Треугольный (норманнский)»).

- [x] **Деление поля.** В списке «Деление поля» выбрать «Четверочастный»: рядом появляются выбор второго цвета и поле с кодом, в превью две противоположные четверти закрашены вторым цветом (по умолчанию золотой). Пройти по всем 12 вариантам: превью меняется каждый раз. Включить «Обводку» фона: линии деления рисуются цветом обводки. То же на шестиугольнике и круге: второй цвет не выходит за форму. «Без деления» убирает второй цвет и его поле.
- [x] **Прозрачность поля.** При делении поставить «Прозрачность» фона 60 %: поле полупрозрачное целиком, синее поверх красного не даёт фиолетового.
- [x] **Второй контур.** Включить «Второй контур»: внутри края тонкая линия на ровном расстоянии (толщина 2 %, зазор 2 %). Пройти по всем формам, особенно «Барочный» и «Турнирный (с вырезом)»: линия везде параллельна краю. Включить и выключить «Обводку» фона: зазор всегда отсчитывается от внутренней кромки обводки. Зазор 0 ставит линию вплотную к краю (или к обводке), толщина 0 убирает линию; цвет меняется.
- [x] **Поворот.** В блоке «Иконка» ползунок «Поворот» и число рядом двигаются вместе, превью поворачивается вокруг центра иконки; число вне −180…180 обрезается до границы.
- [x] **Сдвиг и отражение.** «Сдвиг по X» и «Сдвиг по Y» (−50…50 %) смещают иконку; кнопки со стрелками (влево-вправо, вверх-вниз) подсвечиваются, пока отражение включено; кнопка со стрелкой назад сбрасывает поворот, сдвиг и отражение.
- [x] **Поворот не переносится.** Задать поворот и сдвиг, нажать «Выбрать», открыть редактор на другом токене: поворот и сдвиг нулевые, а цвета, форма, деление и контур те же. В открытом редакторе выбрать «Выбрать иконку» → другую иконку из библиотеки: поворот, сдвиг и отражение сбросились.
- [x] **Повторное открытие.** Сделать иконку с делением, вторым контуром и поворотом, открыть её же портрет снова: деление, цвета, контур и поворот восстановились.
- [x] **Подсказка контраста.** Сделать цвет иконки и цвет фона одинаковыми (например `#7a1f2b`): под предпросмотром слева появляется рамка «Иконку плохо видно на фоне (1.0:1)» с квадратиками «Цвет иконки» и «Цвет фона». Клик по квадратику меняет цвет, рамка исчезает. Белая иконка с чёрной обводкой (блок «Иконка», «Обводка») на тёмно-красном фоне с золотым делением: предупреждения нет. Выключить обводку (или поставить ей прозрачность ниже 50 %): появляется «(2.1:1)». Фон выключен или прозрачнее 50 %: предупреждения нет. С делением поля подсказывается только цвет иконки.
- [x] **Цвет фракции.** В мире с Azimuth открыть Iconic (меню «⋮» или ПКМ в каталоге) на (а) актёре-фракции (`azimuth.faction`, у него есть цвет), (б) глобальном объекте с назначенной фракцией, (в) токене такого объекта на сцене: кнопки с флажком у цвета иконки и у цвета фона активны, во всплывающей подсказке имя фракции, клик ставит её цвет. У обычного актёра без фракции кнопки неактивны.

## Проверить руками (этап 4)

Перезагрузить Foundry (F5). Iconic включён.

- [x] **Листы без кнопки, портрет на месте.** Открыть лист персонажа, NPC, фракции, глобального объекта (системный и Azimuth), лута и предмета. Навести на портрет: никакого значка с иконками нет. Портрет на листах фракции, глобального объекта и NPC квадратный, 100×100, как раньше, рядом с полями. Клик по портрету открывает штатный выбор файла Foundry.
- [x] **Iconic открывается сам.** На этих же листах меню «⋮» → «Iconic» (и ПКМ по актёру или предмету в боковой панели) открывает окно Iconic. С выключенным Iconic в мире листы выглядят так же и без ошибок.
- [x] **Цепочка цвета фракции: Iconic → Azimuth → SpaceHolder.** (а) Глобальный объект Azimuth с назначенной фракцией системы (`faction`): Iconic через «⋮» — кнопки с флажком у цвета иконки и цвета фона активны, в подсказке имя фракции, клик ставит цвет фракции. (б) Сама фракция системы и фракция Azimuth: то же с её цветом. (в) Токен такого объекта на сцене: в настройках токена меню окна «⋮» → «Iconic» (если пункта нет, открыть Iconic с листа актёра этого токена): цвет тот же. (г) Объект без фракции и обычный персонаж: кнопки неактивны. (д) Сменить цвет фракции, снова открыть Iconic на объекте: предлагается новый цвет.
- [x] **Таймлайн.** Редактор события → кнопка выбора иконки открывает обычный выбор файла Foundry; выбранная картинка попала в маркер, крестик её очищает.
- [x] **Консоль.** После загрузки мира в консоли (F12) нет ошибок про `icon-library`, `icon-picker` или `iconic-link`; `game.spaceholder.pickIcon` не существует.
