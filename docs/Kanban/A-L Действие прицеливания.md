# Действие прицеливания

Сейчас место попадания выбирается автоматически (диалог выбора группы убран: он ломал темп игры) — группа и часть случайные. Целиться в конкретное место нельзя: действия «Прицелиться» нет.

## Сделать

- Действие «Прицелиться» по конкретному противнику: игрок заранее выбирает, куда хочет попасть (часть тела или группа), и тратит на это ОД.
- Результат не гарантирован: выбор срабатывает только на **крите** — «яблочко» по цели ([[S-L Качество попадания]]) — и только у режимов с эффектом крита «Выбор части тела» (`critEffect: pickPart`; по умолчанию его даёт одиночный выстрел, очередь и авто — нет). Мимо «яблочка» — случайная группа и часть.
- Выбор делается действием до выстрела, а не окном в момент попадания.
- Связано: [[NR Попадание по хитбоксу]], [[NR Анатомия — группы]].
- Пояса `hit-luck` убраны ([[S-L Качество попадания]]); зона дуги теперь даёт уверенность ([[S-L Уверенность выстрела и сопротивление попаданию]]).
- Сейчас крит с `pickPart` берёт группу из метки на цели (`system.anatomy.hitGroupOverride`, диалог «Группы анатомии» в редакторе анатомии) — это временная замена. Действие «Прицелиться» должно её заменить: выбор делает стрелок заранее (часть тела или группа), а метка на цели уходит.
