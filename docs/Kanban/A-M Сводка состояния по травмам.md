# Сводка состояния по травмам

Агрегатор текущих травм актёра в одно короткое «состояние» (для быстрого HUD рядом с портретом, возможно для листа/токена).

- Зависит от доработки травм и анатомии ([[S-L Доработка травм]], [[NR Анатомия — группы]], [[B-L Органы]]).
- Сначала — модель: какие травмы и группы влияют, шкала состояний, пороги.
- Потом — отображение в HUD: в `templates/hud/token-quick-hud.hbs` уже стоит плейсхолдер `.sh-token-quick-hud__health` (в нижней панели между портретом и действиями); подставить данные в `_buildContext()` (`token-quick-hud.mjs`).
