Рефактор анатомии: игрок целится в **группу**, не в конкретную лодыжку.

## Типы групп

Есть у любой анатомии (набор может расширяться): манипуляция, передвижение, сенсорная, критическая.

Это **типы**. Экземпляров одного типа может быть несколько и они независимы: ноги и крылья ангела — две группы передвижения (ходить / летать). Зрение и слух — две сенсорные, хотя обе живут в голове.

Примеры передвижения: ноги человека, гусеницы танка, двигатели корабля.

## Пайплайн

1. Стрелок выбирает группу («хочу сбить передвижение»), не часть тела.
2. Попадание резолвится внутри группы (см. [[NR Попадание по хитбоксу]], [[NR Удачность выстрела]]).
3. Способность группы = сумма текущего HP частей / сумма max HP. Меньше max → штраф к этой способности.

## Что выкинуть / не трогать пока

- Экспозицию по сторонам, скорее всего, убрать — в 2D она плохо читается и неотличима от рандома.
- Сопротивление тканей частей и органы — не прорабатывать, пока нет групп. Органы: [[NR Органы]].
- Связи `adjacent` / `behind` / `parent` **оставить** (пробитие рейлганом через части).
- 3D-анатомию через Three.js не развивать. Редактор 2D оставить, подтянуть под группы.
- Человек: грудь, живот, **спина нужна** (жилет спереди/сзади разный).

Не путать с 3D-рельефом глобальной карты.
