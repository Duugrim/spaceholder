## Типы групп

манипуляция, передвижение, сенсорная, критическая. Это **типы**. Экземпляров одного типа может быть несколько (ноги / крылья ангела). Часть может входить в несколько групп (голова = сенсоры + крит).

Способность = сумма current HP частей / сумма max HP.

## Часть тела

На сетке: `id`, `name`, `x`/`y`, `maxHp`, `material` (обязателен), `tags`, `relations`, `heightFrac`, `faces[]`, `inners[]`.

Выпилить: `exposure`, `bodyLayers`, `status` в JSON, `internal`, 3D Health (`position3d`, Three.js), `weight` как вход попадания.

**Стороны (`faces`)** — не HP. Торс: `front`/`back` (жилет спереди ≠ сзади). Конечность: одна сторона. Броня: `coveredParts` `{ partId, face }`.

**Внутренности (`inners`)** — органы, без клетки. Доля `%`, статусы без своего HP. См. [[NR Органы]].

Человек: **`upperTorso`** / **`lowerTorso`** вместо груди+спины+живота. Спины как кружка нет.

## Пайплайн выстрела

Сначала выстрел, не выбор группы. Удачность дуги × центровость → `hitLuck`, потом диалог (или override на персонаже). Таблица: [[NR Попадание по хитбоксу]].

## Проверить руками

1. Пресет humanoid: нет chest/back/abdomen, есть upperTorso/lowerTorso с front/back, группы на Health.
2. Редактор 2D: вкладка групп, стороны, органы; вкладок экспозиции и 3D нет.
3. Броня: покрытие `partId` + `face` (грудь жилета = upperTorso front).
4. `game.spaceholder.getGroupAbility(actor, groupId)` в консоли даёт HP%.
