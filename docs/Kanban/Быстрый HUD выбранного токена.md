# Быстрый HUD выбранного токена

Нижняя панель над макро-рядом: портрет и кнопки токена, кнопка «Атаковать», общий поток действий. Выше — карточки предметов (в руках + быстрый доступ) и ряд выбранных предметов.

## Реализация

- `module/helpers/token-quick-hud.mjs` — резолв токена, состав и раскладка, выбор, хуки обновления
- `templates/hud/token-quick-hud.hbs`, `src/scss/components/_token-quick-hud.scss`
- `module/helpers/weapon/attack-chain.mjs` — `canAttackWithItem`, `attackWithItem`, `previewItemAttack`, `switchWeaponMode`, `previewModeSwitchAp`
- `module/documents/item.mjs` — `item.canAttack`, `item.attack({ token })`
- `module/helpers/actions/action-service.mjs` — избранное, `uiOnly`, пункты «Режим стрельбы» и «Быстрый доступ» в ПКМ, макросы действий
- `module/helpers/simple-context-menu.mjs` — общее лёгкое контекстное меню (лист + HUD)
- `module/helpers/weapon/weapon-model.mjs` — `block.displayStyle`, `buildAmmoDisplay()`

## Поведение

- Атака — возможность предмета, а не действия по линия×режим. Режим меняется явно (селектор в HUD или ПКМ → «Режим стрельбы») и запоминается в `system.weapon.state`.
- Карточки: предметы в руках + оружие с `system.quickAccess` (тусклые, после разделителя). Клик переключает выбор; выбор — `flags.spaceholder.quickHudSelectedItemIds`.
- ⋮ убрана, меню предмета — ПКМ (и клавиша меню).
- «Атаковать» активна при ровно одном выбранном оружии; бейдж `~N` = недостающие шаги цепочки + первый выстрел.
- Общий ряд: `showInQuickbar !== false`, без действий предметов с карточкой (настройка клиента), поток чипов в 2 строки, `+N` и раскрытие.
- ПКМ по действию → «В избранное / Убрать». Чип действия можно перетащить на хотбар → макрос `game.spaceholder.runActorAction`.
- Лист: кнопка ⌖ на карточке предмета в руках вызывает `item.attack()`.

## Проверить в Foundry

- **Режимы:** оружие с 2+ режимами. Смена в селекторе HUD и через ПКМ: бесплатная применяется сразу, платная спрашивает подтверждение и списывает ОД, карточка показывает новый режим.
- **Регресс:** у старого режима включён `exitCost`, у нового выключен `enterCost` → после смены режим сохранён, повторная атака не платит вход.
- **«Атаковать»:** 0 / 1 / 2 выбранных (неактивна с подсказкой / работает / неактивна). Незаряженное — в цепочке перезарядка или неактивна с причиной. Быстрый доступ — в цепочке «Взять в руки». `~N` ≈ списанию за первый выстрел.
- **Лист:** ⌖ на карточке в руках запускает атаку; во вкладке действий нет «Имя: линия / режим».
- **Выбор:** переживает смену токена и перезагрузку; убранный из рук предмет пропадает из выбора.
- **Быстрый доступ:** ПКМ по оружию в инвентаре листа → «В быстрый доступ» → тусклая карточка в HUD.
- **Общий ряд:** нет «Взаимодействовать» и дублей; 2 строки; `+N` верный при 1366×768, 900×700, 680×600; Tab не попадает в обрезанные чипы; Escape закрывает раскрытие.
- **Избранное:** ПКМ по действию добавляет/убирает, порядок обновляется (и в листе).
- **Хотбар:** перетащить чип действия на слот → макрос выполняет действие с правильным токеном.
- **Портрет и кнопки:** клик по портрету — просмотр портрета; центрирование, лист, настройки токена.
- **Патроны:** в редакторе блока «Отображение патронов» = Числом / Полосой (и для батареи) / Точками (≤ 12, иначе число).
- **Эффекты:** статус с токен-HUD появляется иконкой рядом с ОД.
- **Обновление без перевыбора токена:** подбор из кучи, выброс из листа, начало/конец боя, добавление эффекта.
- Игрок со своим/чужим токеном, ГМ и последний выбранный токен; EN/RU.
