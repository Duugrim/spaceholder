# Механика овердрафта

В бою ОД — жёсткий лимит ([[S-M ОД атаки — дыры]]): не хватает — действие не происходит. Овердрафт — исключение: персонаж уходит в минус по ОД.

## Решить

- Кто разрешает: ГМ по запросу (живой запрос ГМу или очередь, как у остальных действий с правами ГМа — [[B-M Менеджер действий ГМа — остальные потребители]]) и/или автоматически по параметру персонажа. Какому параметру — не выбрано; кандидат — [[B-L Героизм, второе дыхание и интуиция]].
- Что значит «в минус»: долг переходит в следующий пул (пул начинается с `max − долг`) или прощается. Сейчас `refreshApPool` долг не считает.
- Предел: насколько глубоко можно уйти в минус.
- Интерфейс: при нехватке ОД вместо отказа предложить «запросить овердрафт»; кнопка «Атаковать» в HUD сейчас в таком случае просто выглядит недоступной.
- Движение: оно уже сейчас обрезается по остатку (токен переместился до списания) — отдельно решить, ограничивать ли его заранее.

## Куда встраивать

`spendAp` (`transaction-ledger.mjs`) решает через `planApSpend` (`actions/ap-pool.mjs`): режимы `AP_SHORTAGE.BLOCK` (по умолчанию) и `CLAMP` (движение). Овердрафт — третий режим; отдельно — решение, кто его выбирает.
