# Характеристики актёра

Источник: `actor.mjs` → `_prepareCharacterData` (только `character`).

Порядок: wearable-моды на `abilities.*.value` → `mod` → `derivedStats` / `speed`.

## База (`system.abilities.*.value`)

| ключ | имя |
|------|-----|
| end | Выносливость |
| str | Сила |
| dex | Подвижность |
| cor | Координация |
| per | Восприятие |
| int | Интеллект |
| luc | Удача |

`mod = floor((value − 10) / 2)`

Wearable (`equipped` + `isModifiers`): сумма `mode: add` к `abilities.*.value` (runtime).

## Производные (`system.derivedStats` + `speed`)

V = value, M = mod.

| поле | формула |
|------|---------|
| healthBonus | endM |
| carryWeight | floor(15 + strV×6 + endV×5) |
| liftWeight | floor(strV×12) |
| meleeDamageBonus | strM |
| jumpHigh | max(0, 0.25 + (strV+dexV−20)×0.04) м |
| jumpLong | max(0, 1.8 + (strV+dexV−20)×0.15) м |
| travelSpeed | max(0, 5 + dexM) м / slice |
| movementTimeSliceAp | CONFIG `movementApTimeSlice` (def 10) |
| **speed** | sliceAp / max(minDist, travelSpeed); minDist = CONFIG `movementMinDistancePerSlice` (0.25) |
| turnsPerRound | max(1, floor(dexV×intV / 100)) |
| agilityScore | 10 + dexM + corM |
| actionSpeed | max(0, 8 + corM×2) |
| reactionScore | 10 + dexM + perM |
| accuracyScore | 10 + corM + perM |
| awarenessScore | 10 + perM×2 |
| learnRateScore | 10 + perM + intM |
| willScore | 10 + intM×2 |
| intuitionScore | 10 + lucM + intM |
| heroismPoints | max(0, 1 + lucM) |
| secondWindBonus | 1 + endM + lucM |
| maxApFromAbilities | floor(dexV × intV) |

ОД в бою: `actionPoints.max` = `maxApFromAbilities` (`getMaxApFromAbilities`).

## Прочее

- **HP частей:** `current = maxHp − floor(sum(injury.amount)/100)` — не derivedStats.
- **NPC:** только ability mods + `xp = cr²×100`. Нет derivedStats.
