# Одновременный огонь из нескольких предметов

В быстром HUD выбор уже множественный (`flags.spaceholder.quickHudSelectedItemIds`), режимы явные и запоминаются. «Атаковать» сейчас работает только при одном выбранном оружии.

- Прицеливание (`aiming-manager.mjs`) держит одну сессию: `currentOptions.weaponV3`, `_fireBusy`, `_autoFireTimer` — одиночные.
- Продумать правила: общий прицел или по очереди, стоимость ОД, разные режимы (очередь + одиночный).
- Точка входа: `attackWithItem` / кнопка «Атаковать» в `token-quick-hud.mjs` (`_buildAttackContext`).
