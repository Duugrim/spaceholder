Единый путь для всего, что клиент игрока делает с правами ГМа. Первый потребитель — урон по чужим токенам (раньше у игрока он молча не проходил — см. «Список багов»). Не связан с одобрением ГМом-человеком.

Как устроено и API: `docs/code/reference/GM_ACTIONS.md`. Ручные проверки пройдены.

## Что сделано

- Живой запрос назначенному ГМу (ack, результат); нет ГМа — очередь во флагах User игрока.
- Окно «Действия игроков в ваше отсутствие» при входе ГМа: группы по типу (урон, глобальная карта, прочее), галочки; неотмеченное отменяется.
- Заметка в чате: «Действие ожидает ГМа» → исчезает после применения / «Отменено ГМом».
- Подключён `damage.apply`.
