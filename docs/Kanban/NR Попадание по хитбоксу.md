Второй множитель успеха после [[NR Удачность выстрела]]. Цель пока с **круглым** хитбоксом.

## Геометрия

Нужна близость попадания к **центру** круга (касательная / угол от центра — в сумме ~90°, уточнить в калькуляторе). Центр — успешное попадание «куда хотели». Край — скользящее: броне легче отклонить/рикошет, при низкой удачности выстрела — промах.

Комбинация удачности дуги и «центровости» — формула или таблица (уточнить при реализации). Навскидку: удачный выстрел + край ≈ всё ещё попадание, но угол брони; неудачный + край ≈ промах; неудачный + центр ≈ попадание, но слабее.

Уклонение цели: визуал токена тот же, **хитбокс меньше**.

## Куда попали

Стрелок либо заранее выбрал группу ([[NR Анатомия — группы]]), либо его спрашиваем, либо берём случайно из **доступных**.

Укрытия выключают части/группы: окоп → ноги недоступны, если не стреляем сквозь землю. В UI выбора — схема анатомии с закрытыми зонами.

Сейчас v3 бьёт в `core` / случайную часть — это ломается этой задачей, не чинить отдельно заплаткой.
