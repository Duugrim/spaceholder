Второй множитель успеха после [[NR Удачность выстрела и прицеливание]]. Цель с **круглым** хитбоксом. Выбор группы — **после** попадания в токен ([[NR Анатомия — группы]]).

## Геометрия

Точка A — атакующий. Точка B — центр цели. C — пересечение луча с окружностью хитбокса. Центровость `centrality` = `1 − d/R` (0 → край, 1 → центр). Угол к касательной в C связан: ближе к 90° ≈ центр.

Уклонение: визуал токена тот же, **хитбокс меньше**. Масштаб хитбокса — отдельный параметр листа `system.hitboxScale` (процент, 100 = размер токена, обычно ≤ 100%), применяется в `_targetHitRadius`, см. `target-size-scaling.md`. DEX и другие характеристики на хитбокс не влияют.

## hitLuck = combine(centrality, зона дуги)

> **Заменено.** Пояса `hitLuck`, `armorScale` и настройка `hitLuckCombine` убраны: качество попадания теперь только центровость → множитель энергии снаряда и крит, см. [[S-L Качество попадания]]. Ниже — как было.

Мировой сеттинг `spaceholder.hitLuckCombine`: **`multiplier`** (дефолт) | `penalty`.

Множители: фиолет **1.5**, зелёный **1.0**, жёлтый **0.75**, оранжевый **0.5**, красный **0.25**.
Штрафы: фиолет **+0.5**, зелёный **0**, жёлтый **−0.25**, оранжевый **−0.5**, красный **−0.75**.

Пояса по итоговому hitLuck:

- **> 0.75** — «чистое попадание»: полный урон, броня ×1. Место выбирается автоматически; выбрать часть сможет только будущее действие [[A-L Действие прицеливания]].
- **(0.50, 0.75]** — «уверенное попадание»: полный урон, броня ×1.
- **(0.25, 0.50]** — группа, броня как под 45° (×√2).
- **(0, 0.25]** — «задел»: override на персонаже игнорируется (случайная группа), броня как под 75° (×1/cos(75°) ≈ 3.86).
- **≤ 0** (или ниже ε ≈ 0.01 в режиме множителей) — раньше «пролёт мимо» (снаряд летел дальше, зона +1 к зелёному). **Выключено** (`HIT_LUCK_FLY_PAST_ENABLED`): теперь это тоже «задел». Попал — попал, не попал — не попал; код пролёта сохранён за флагом, см. «Удачность и пролёт мимо» в `SHOOTING_SYSTEM.md`.

Диалога выбора места нет (он прерывал игру): группа — override на персонаже «всегда в эту группу» или случайная, часть — случайная в группе.

Укрытие как объект сцены — не этот срез; на части только `heightFrac`.

Fallback `core` / случайная часть — ломается этой задачей.

## Проверить руками

Хитбокс проверен (размер хитбокса, промах у края, соседи при взрыве, независимость от AGI). Проверки качества попадания (бывшая «удачность попадания, группа») — в конце [[S-L Качество попадания]].

## АоЕ (circle / cone) — без удачности и центровости

Только `coverage`. Сегмент задаёт `coverageMode` (`proportional` по умолчанию | `any` | `center` | `full`), детали — `docs/code/reference/SHOOTING_SYSTEM.md`. Группа/часть — случайная, диалога нет. Раньше АоЕ-попадания молча пропускались (центровость = 0 → «мимо»).

Проверки АоЕ пройдены; `excludeDirectHit`, `ignoreDirectHitCover`, `lineOfSight: false` и ширина «тени» за целью отмечены по доверию — [[B-M Инструменты проверки АоЕ]].

Ширина «тени» за целью — `TOKEN_COVER_RADIUS_FACTOR` в `shot-manager.mjs` (0.5 → ±30°); подбирается на глаз.
