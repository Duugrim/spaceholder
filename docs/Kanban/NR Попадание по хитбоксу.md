Второй множитель успеха после [[NR Удачность выстрела и прицеливание]]. Цель с **круглым** хитбоксом. Выбор группы — **после** попадания в токен ([[NR Анатомия — группы]]).

## Геометрия

Точка A — атакующий. Точка B — центр цели. C — пересечение луча с окружностью хитбокса. Центровость `centrality` = `1 − d/R` (0 → край, 1 → центр). Угол к касательной в C связан: ближе к 90° ≈ центр.

Уклонение: визуал токена тот же, **хитбокс меньше**.

## hitLuck = combine(centrality, зона дуги)

Мировой сеттинг `spaceholder.hitLuckCombine`: **`multiplier`** (дефолт) | `penalty`.

Множители: фиолет **1.5**, зелёный **1.0**, жёлтый **0.75**, оранжевый **0.5**, красный **0.25**.
Штрафы: фиолет **+0.5**, зелёный **0**, жёлтый **−0.25**, оранжевый **−0.5**, красный **−0.75**.

Пояса по итоговому hitLuck:

- **> 0.75** — полный урон, броня ×1, можно выбрать группу **или** часть.
- **(0.50, 0.75]** — полный урон, броня ×1, только группа.
- **(0.25, 0.50]** — группа, броня как под 45° (×√2).
- **(0, 0.25]** — задел: группу не выбираем (случай из доступных), броня как под 75° (×1/cos(75°) ≈ 3.86).
- **≤ 0** (или ниже ε ≈ 0.01 в режиме множителей) — промах по токену: снаряд летит дальше, зона выстрела +1 к зелёному (не до фиолета).

После попадания — диалог стрелку (итог + доступные группы) или override на персонаже «всегда в эту группу».

Укрытие как объект сцены — не этот срез; на части только `heightFrac`.

Fallback `core` / случайная часть — ломается этой задачей.

## Проверить руками

1. Standard + v3: в чате зона, центровость, **hitLuck** и пояс. При попадании — диалог группы (или override).
2. Зелёный + центр (>0.75): можно выбрать часть; полный урон.
3. Красный + край: либо задел/случайная группа, либо снаряд летит дальше с зоной на ступень лучше.
4. Simple (GM payload): удачность не считается, как раньше.
5. Кламп за спиной: red + clamped, выстрел идёт.
