Замена текущих дуг. Старая карточка: [[Изменение влияния дуг прицеливания]].

## Дуги ≠ отклонение

Случайный разброс направления — **только** параметр spread оружия. Дуги отклонение **не** крутят.

Дуги задают **удачность выстрела** (куда попали / насколько «попал куда целился»). Фиолетовую зону пока не трогать — назначение не решено.

| Зона | Смысл |
|------|--------|
| Зелёная | Подготовленный выстрел, с высокой вероятностью туда, куда целился |
| Жёлтая | Слегка неудачный |
| Оранжевая | Неудачный |
| Красная | Ещё физически можно выстрелить, но крайне случайно |
| Мёртвая | **Стрелять нельзя** (сейчас выстрел в спину проходит) |

Дефолт 90° на сторону → 180° вперёд, задние 180° закрыты.

## Прицел

Не линия центр→курсор. Линия из центра, изначально **вперёд**, доворачивается к курсору со скоростью от эргономики. Не выходит за дуги. Визуал — лазер с градиентом в прозрачность.

Удачность выстрела стыкуется с геометрией попадания: [[NR Попадание по хитбоксу]]. Без групп ([[NR Анатомия — группы]]) удачность почти некуда применять.
