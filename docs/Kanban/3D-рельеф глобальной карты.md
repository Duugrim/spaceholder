# 3D-рельеф глобальной карты

Проверить в Foundry на сцене с `isGlobalMap`. Жёсткое обновление (F5), чтобы сбросить старый terrain v1.

- Кнопка-гора сразу показывает 3D-карту (не серый экран). Панель кистей слева снизу, над хотбаром; её можно перетащить за верхнюю полоску.
- Импортированная карта в 3D: склоны сглажены, без квадратных «ступеней» клеток. Биомы могут чуть смешиваться на границах.
- Raise/Lower работают по видимой 3D-карте, «Сохранить карту» для этого не нужен.
- Выключить 3D → клеточный импорт/редактор. «Редактировать» само выключает 3D.
- «Глаз» открывает окно осмотра.
