## Принцип

Промах всегда по объективной причине, а не «кубы решили». Если цель не сопротивляется — попадание **точно**. Дуги прицеливания задают, насколько уверенно выстрел произошёл (отброшенный в сторону ствол ≠ тир): красная зона — «ещё можно развернуть оружие, но наобум».

## Модель

**Уверенность выстрела** — число от зоны дуги: красная 1, оранжевая 2, жёлтая 3, зелёная 5 (4 пропущено намеренно). Фиолетовая — особая, по умолчанию её нет ни у кого ([[B-M Фиолетовая зона и выжидание]]).

**Сопротивление попаданию** — число у цели. Выстрел попадает, если уверенность **больше** сопротивления. Числа ниже выведены из диктовки (последняя зона, которая уже не попадает), в коде — константы `HIT_RESISTANCE_STATES`:

| Состояние цели                              | Сопротивление | Не попадает                      |
| ------------------------------------------- | ------------- | -------------------------------- |
| не в бою, стоит                             | 0             | —                                |
| в бою                                       | 1             | красная                          |
| в бою, активно движется (обычная перебежка) | 2             | + оранжевая                      |
| в укрытии                                   | 3             | + жёлтая (пролетает над головой) |
| полностью спрятана за укрытием              | 5             | + зелёная (зависит от укрытия)   |

Откуда берутся состояния — [[A-L Состояния цели для сопротивления попаданию]]. В первом заходе: «в бою» из боя + общий слот модификатора сопротивления (эффекты).

## Решено

- Состояния **не складываются**: сопротивление = максимум по состояниям + плоский модификатор эффектов (`system.hitResistanceMod`, может быть отрицательным, итог не ниже 0).
- Числа **фиксированные**, именованные константы в `shot-confidence.mjs` (настройки нет): уверенность красная 1, оранжевая 2, жёлтая 3, зелёная 5; сопротивление в бою 1, движется 2, в укрытии 3, спрятана 5.
- Фиолетовая зона = 6: выше любого состояния (в т.ч. полного укрытия). Пока фиолетовой зоны нет ни у кого; если крит стрелка не должен пробивать полное укрытие — поменять константу.
- Зона на энергию не влияет ([[S-L Качество попадания]]).
- Частичное/полное укрытие и «укрытие спереди» — в [[A-L Состояния цели для сопротивления попаданию]], не здесь.
