# Ближний бой и кулаки

Продолжение [[Характеристики актёра]]. Усилие = STR, урон = `damage + effortShare/100 × STR` (поле `effortShare` в записи урона уже есть, нож/меч/копьё переведены).

## Сделать

- Кулак как естественное оружие из анатомии (руки, ноги, зубы), доля 25% от STR. Идёт через ветку «импровизированная атака» из [[C-M Атака любым предметом]], без отдельного пути.
- Предпросмотр атаки показывает итоговый урон при текущей STR (строки урона на листе нет).
- Боевые искусства поднимают долю кулака (навык/перк).
- Нелетальный режим: пока его нет, уничтоженная голова (100 HP) — смерть; кулак 25% убивает голову за 4 удара.
- Метательное оружие может брать ту же долю.
- Отдачу и упор считает [[C-L Стабильность]], не урон.
- Дуги прицеливания ближнего оружия шире: мечом сейчас трудно попасть в нужную зону удачности, размахнуться по цели должно быть легче.

## Проверить руками

1. У актёра без оружия есть кнопка атаки кулаком; урон 25 при STR 100, 13 при STR 50.
2. Меч при STR 50 бьёт вдвое слабее, чем при STR 100.
3. Огнестрел не меняется.
