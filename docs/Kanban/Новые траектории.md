Хотим расширить список основных строительных блоков траекторий:

### Swing
У нас уже есть swing, но это сложная конструкция из конусов. Переименовать старый swing во что-то другое, а новый свинг реализовать так:

1. Рисуется конус
2. В этом конусе в зависимости от настроек (правый или левый свинг) берём грань
3. Грань как линия движется по конусу, поворачиваясь. Точка поворота - исходная точка конуса, разумеется.
4. Когда линия пересекается с хитбоксом - это попадание.

**Сделано (код):** старый → `swingFan`/`legacySwing`; новый `swing` = edge sweep (`shot-manager` + draw). Payloads: `melee_knife_cut`, `melee_sword_cut`, `melee_spear_cut`. Нож/меч/копьё в каталоге на complex+payload. 


### Режимы удара swing (`hitMode`)

Размах **останавливается о первую стену или токен**. Как касание превращается в урон — по режиму (детали: `docs/code/reference/SHOOTING_SYSTEM.md`, раздел 4a):

- `simple` — первый токен, без центровости и покрытия;
- `side` (по умолчанию) — центровость по линии через точку касания, перпендикулярной кромке: ровный удар = точный;
- `area` — размах останавливается, но покрытие считается по всей зоне (обычная АоЕ); новая опция АоЕ `coverageForFullEffect` (%);
- `deep` — размах продолжается до другой стены/токена, центровость по ближайшему к центру положению кромки.

Payloads: нож и копьё переведены на `area` + `coverageMode: any` (раньше пробивали всех через `next`), меч — `side`. Подбирается по ощущениям.

**Проверить руками:** пройдено (ближний бой, swing: меч, нож, копьё, `hitMode`).
