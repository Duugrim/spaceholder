## Правила

- По ширине токена: центральная зона ≈ 1/3 ширины (круглое число, настройка мира `hitFullZone`, по умолчанию 30%) — **полное попадание**, множитель ×1.
- В самом центре маленькая зона «яблочко» (`hitCritZone`, по умолчанию 10%) — **критическое попадание** (крит цели).
- От края зоны полного попадания к краю хитбокса множитель **равномерно** падает от ×1 до `hitEdgeEnergy` (по умолчанию ×0.1 на самом краю). Групп «до/после порога» нет: малая разница на границе не превращается в «пробил / не пробил».
- Множитель применяется **к энергии выстрела**, из которой считается пробитие, а не напрямую к урону; урон выводится из энергии по закону брони («Снижение урона бронёй» снаряда, 100% — пропорционально). Так падение множителя заменяет угол брони (√2, 1/cos 75° убраны): косая плита поглощает ту же энергию из меньшего остатка, а цель без брони просто получает меньший урон — у крупных калибров он всё ещё может быть смертельным.
- Эффект крита — параметр **режима огня** (`critEffect`: «По режиму огня» / «Ничего» / «Выбор части тела»). По режиму: одиночный выстрел — выбор части тела, очередь и авто — ничего (пока). Не каждый снаряд очереди может выбирать часть.
- Выбор части/группы при крите: пока берётся группа, помеченная у цели (`system.anatomy.hitGroupOverride`, диалог «Группы анатомии»); выбор заранее действием — [[A-L Действие прицеливания]].
- Фиолетовая зона стрелка — тоже «крит», но со стороны стрелка ([[B-M Фиолетовая зона и выжидание]]) — не смешивать.

## Решения (из диктовки)

- Пояса `partOrGroup / group / group45 / graze` и `armorScale` — убраны, заменены плавным множителем энергии (см. правила).
- Выбор части/группы привязан к криту («яблочко» по цели), а не к зоне полного попадания; настраивается эффектом крита режима.
- Что даёт крит: для большинства одиночных выстрелов — выбор части тела, для автоматического огня пока ничего. Другие эффекты — отдельная карточка (Backlog).

## Проверить руками

Качество попадания — только центровость; зона дуги на него не влияет. Радиус хитбокса токена 1×1 клетка — полклетки, поэтому по умолчанию: «яблочко» (крит) — ближе ≈ 0,05 клетки к центру, полное попадание — ближе ≈ 0,15 клетки, дальше энергия равномерно падает до ×0.1 на самом краю (0,5 клетки). Пролёт мимо решает только уверенность выстрела ([[S-L Уверенность выстрела и сопротивление попаданию]]): вне боя сопротивление цели 0, поэтому здесь касание хитбокса — попадание. Журнал атаки пишется при выходе из прицеливания (ESC, клик ПКМ или «Отмена»): строка «Атака» в чате, «Показать попадания» раскрывает цель. Травмы создаёт только оружие v3; на отладочном прицеливании (GM-диалог, payload без урона) травм и групп нет, но строки попаданий с центровостью и энергией в журнале есть.
