Черновик, не делать сразу. Формулу v4 ([[B-XL Формула пробития v4]]) **не трогать**.

Слить ballistic / concussive / piercing / cutting в один тип **кинетический**. Вместо четырёх сопротивлений — параметр **проникновения** (пуля высокая, дубина ~0: глубже только если уничтожила часть).

Напряжение с уже существующими бронепробитием и твёрдостью — три похожих ручки. Подумать, что оставить, прежде чем кодить.

Falloff по-прежнему на боеприпасе (или на оружии, если патронов нет).

Связь с травмами: если типы сольются, исход травмы ([[S-L Доработка травм]]) нельзя выбирать только по типу урона — нужен контекст (проникновение, материал части, способ доставки).

Параметр проникновения у урона сможет решать сразу несколько проблем для нашей системы: в частности, он сможет отвечать на вопрос, почему высокомощная пуля прошла цель насквозь и нанесла не сильно больше урона, чем пистолетная.
