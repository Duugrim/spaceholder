## Вкладка «Навыки»

Подвкладки (справа налево логика «от практики к теории»):

1. **Физические** — практика важнее теории; в бою привязаны к расчётам; пресет обязателен.
2. **Смешанные** — руки + знание (столярка, скульптура).
3. **Знания** — чисто теория (науки).

Смешанные и знания: короткий пресет самого важного + свободное «+ добавить навык» (название, уровень). Это запись «персонаж умеет», не полноценная механика.

Физические тоже могут иметь свободные записи, но ядро — захардкоженное дерево.

## Дерево физических

Не обязательно бинарное. Не укорачивать ветку, если у типа нет развилки (один «дротикомёт» — ок, глубина та же). Универсально для человека / танка / робота: те же группы, особые модификаторы отдельно.

**Бой** (черновик порядка): бой → ближний / дальний → тип (клинковое / метательное / огнестрел / лазер…) → класс (пистолет / винтовка / одноручное…) → **конкретное оружие** (свободное имя, не пресет).

Опыт только вниз: в ребёнка нельзя вложить больше, чем в родителя. При нулях сначала качается корень («вообще можно драться / стрелять»).

Уровень узла **0–10**: 0 — нет концепции / не держал; 10 — как продолжение тела.

**Физическое развитие** — тоже дерево: лёгкая / тяжёлая атлетика → дальше к конкретным показателям.

## Эффект навыка

Функция «взять эффект навыка»: все узлы ветки учитываются, даже непрокачанные (дерево не схлопывается). Чем ближе к листу — тем больше вклад, но разница «класс ↔ конкретная модель» небольшая (~25%: например класс 4, модель 5), чтобы Макаров vs Glock не ломал стрельбу.

Черновик весов по глубине (сумма по цепочке): корень ~1 … дальний бой ~1.5 … класс ~4 … конкретное ~5. Не «в два раза на каждом шаге».

## Проверить руками

1. Лист персонажа: вкладка «Навыки» после «Характеристики». Три колонки: Физические / Смешанные / Знания. Заголовки колонок остаются на месте при скролле тела.
2. Нет шевронов и нет полей уровня в дереве. У узла с детьми — чёрточка под началом имени; ЛКМ сворачивает/раскрывает. Раскрытый: чёрточка с разрывом и стрелкой вниз, ствол идёт от стрелки. Лист: входящая линия с вертикальной засечкой у текста.
3. ПКМ по любому навыку (включая «Бой»): Изменить (диалог только уровня), Добавить ребёнка (имя + уровень). Удалить — только у extra. Предустановленные имена не переименовываются.
4. ПКМ по заголовку «Смешанные» / «Знания» (и «Физические») добавляет корневой extra. Кнопок «+» в колонках нет.
5. Уровень ребёнка нельзя поставить выше родителя. Снижение «Бой» зажимает потомков и extra в поддереве.
6. В консоли: `game.spaceholder.getSkillEffect(actor, 'combat.ranged.firearms.pistol')` — число 0–10. Aiming/выстрел от навыка не меняется.
