Окно ≈ **3:2**. Два сегмента:
1. **Фронт** (слева/центр): квадрат **1:1** — скважина (пилюля), отмычка вверх, кольцо сегментов.
2. **Разрез** (справа): прямоугольник **1:2** — стопка штырьков снизу вверх.

Пошаговый Skyrim-like взлом **без** ломающихся отмычек. Полный круг 360° по сегментам; звук подсказывает близость; несколько штырьков с HP у уже взломанных.

## Управление
- **Колёсико** над фронтом — отмычка ±1 сегмент
- **ЛКМ** по фронту — проверка
- **ЛКМ** по штырьку — переключение
- В режиме **observe** ввод не двигает состояние

(Клавиатура WASD/стрелки не используем — Foundry их перехватывает.)

## Сегменты и допуск
- Шаг сегмента при генерации: `1 / 2 / 5 / 6 / 10 / 20` °. Сетка **сдвинута на ½ сегмента**, нулевой сегмент строго сверху.
- У штырька: целевой сегмент + допуск `T ≥ 0`.
- **Зона успеха** = целевой ± `T` → ширина `2T+1` (пример `T=2` → 5).
- **Зона hot-звука** = целевой ± `2T` → ширина `4T+1` (пример `T=2` → 9). Hot раньше, чем можно успешно нажать Space.
- `T=0`: успех и hot только в точный сегмент.
- На UI допуск — метка **низкий / средний / высокий** (не число).

## Звук — 4 слота
| Слот | Когда |
|------|--------|
| `segmentHot` | A/D в hot-зоне |
| `segmentCold` | A/D вне |
| `pinPassed` | Space успех |
| `pinReset` | HP→0, штырёк сброшен |

Pitch-вариация на шагах A/D. Опция шума (~5%): Hot↔Cold. В диалоге генерации — выбор файла на каждый слот из пула (дебаг/тюнинг).

## Штырьки / HP (MVP)
- Цель: взломать **все** штырьки.
- Seed-генерация: целевой сегмент; `T ∈ [Tmin, Tmax]`.
- HP (default 3) у **уже взломанных**: провал на активном → −1 HP у соседних взломанных; HP→0 → снова не взломан + `pinReset`.
- Соседи: крайний — один, средний — оба.
- Опция: при провале цель **прыгает** ±N сегментов (не полный реролл).
- Победы: все unlocked. Отдельного поражения нет.

## Экосистема (как hack)
- Диалог: **Start** (локально) / **Send to chat** (invite).
- Invite → Start run → карточка run; owner в `play`, остальные **Observe** (read-only).
- Sync: action log + seed replay; flags + sockets.
- Один seed + params → одинаковые цели/допуски.

## Параметры диалога
Seed, число штырьков 1–20, шаг сегмента, Tmin/Tmax, HP, fail-jump, sound noise, 4 sound selects.

## Scope
- Локальный старт, chat invite/run, observe/sync, seed RNG, звуки, Token Controls, API `openLockpickMinigame`.
- Без типов штырьков, навыков/мира, поломки отмычек, co-op ходов.

## Post-MVP
Типы штырьков (разболтанный и т.п.), скрытые/видимые эффекты на соседей.

## Проверить руками
1. Token Controls → Lockpick; один seed дважды → одинаковые цели/T.
2. Start локально: колёсико cold/hot + pitch; ЛКМ фронт hit → pinPassed + автопереход вверх (иначе вниз); провал бьёт HP соседей (штырёк частично выдвигается); HP→0 → pinReset.
3. Разрез: форма конца = допуск (плоский/сужение); Г-отмычка на активном ряду; клик по штырьку переключает.
3. To chat → Start run → второй клиент Observe видит повороты/штырьки.
4. Смена sound slots в диалоге слышна в игре.
5. Победа обновляет run-карточку.


## Типы штырьков

| Имя         | Тип   | Отличие   | Описание                                                                                                                                                                                                                                                             |
| ----------- | ----- | --------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Обычный     | Перед | \|        | Стандартный допуск                                                                                                                                                                                                                                                   |
| Острый      | Перед | `<`       | Острый перед. Допуск вдвое меньше, и меньше как минимум на 1. Результативная зона не может получится меньше 1 сегмента (но и не должна, если мы трогаем только допуск, а не всю зону).                                                                               |
| Впалый      | Перед | `)`       | В зоне "цель + допуск" есть глухая зона, которая размером "цель + половина допуска". В этой зоне проверка так же будет провалом, но всё ещё звучат звуки-подсказки. "Половина допуска" для глухой зоны округляется вниз, чтобы глухая зона не перекрыла всю целевую. |
| Скошенный   | Перед | `/`или`\` | Только соответствующая половина допуска, в другую допуск не распространяется.                                                                                                                                                                                        |
| Зубчатый    | Перед | `⦚`       | Звучат как корректные и доступны для нажатия только чётные допуски, чтобы получался паттерн "через один": центр, второй, четвёртый...                                                                                                                                |
| Пустой      | Центр |           | Нет особенностей                                                                                                                                                                                                                                                     |
| Распиленный | Центр | `-`       | Штырёк распилен пополам. Для его прохождения нужно найти две целевых зоны в рамках взлома одного штырька (два штырька в одном). Целевые зоны не могут быть ближе, чем 2 допуска.                                                                                     |
| Волнистый   | Центр | `~`       | Канавка в штырьке создаёт вибрации, двигающие целевую зону. При каждой смене сегмента цель (ну и допуск вместе с ней) двигаются вправо или влево (по очереди, туда сюда) на случайное значение сегментов. Это случайное значение лежит между 1 и двумя допусками.    |
| Ребристый   | Центр | `///`     | Данный штырёк влияет не только соседние штырьки, а на все штырьки замка при провале.                                                                                                                                                                                 |
| Полый       | Центр | `⬭`       | Данный штырёк очень легко покидает свою позицию, и считается соседним для любого штырька (и теряет хп при промахе у любого штырька, не только соседнего).                                                                                                            |
|             |       |           |                                                                                                                                                                                                                                                                      |
