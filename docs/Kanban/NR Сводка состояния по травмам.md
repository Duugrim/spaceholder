# Сводка состояния по травмам

Агрегатор текущих травм актёра в одно короткое «состояние» (для быстрого HUD рядом с портретом, возможно для листа/токена).

- Зависит от доработки травм и анатомии ([[Доработка травм]], [[NR Анатомия — группы]], [[NR Органы]]).
- Сначала — модель: какие травмы и группы влияют, шкала состояний, пороги.
- Потом — отображение в HUD (`module/helpers/token-quick-hud.mjs`, блок `__status`).
