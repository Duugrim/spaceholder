# Переработка UI анатомии

Текущий интерфейс анатомии автору не нравится. Конкретно:

- Покрытие брони `partId + face`: порядок в списке — сначала то, что защищает **спереди**. Сейчас порядок случайный. Так как у всех предметов защита только с четырёх сторон, это проблема UI, а не данных.
- Общая переработка UX редактора и вкладки здоровья (см. [[C-M Анатомия — капсульный визуал]]).

Данные и группы — в [[NR Анатомия — группы]]. Рост и скорость вида — [[B-M Рост и скорость вида в анатомию]].
